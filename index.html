Proč self-hosted

Pošta je nejcitlivější data firmy: smlouvy, nabídky, výkresy, personálie. U nás platí jednoduché pravidlo — všechno leží na vašem serveru, v jednom adresáři, který si zazálohujete sami. Žádná telemetrie a žádná pošta ani adresy u nás. Ven jde jen ověření placené licence — a i to vydrží dva týdny bez spojení.

Kompletní poštovní server

SMTP (příjem i odesílání), IMAP4rev1 s IDLE a fulltextovým hledáním, POP3. Trvalá odchozí fronta s opakováním a oznámeními o nedoručení, smarthost i přímé doručování podle MX.

Kalendáře a kontakty

CalDAV a CardDAV pro Apple Mail, Thunderbird i mobily — osobní i firemní kalendáře, přírůstková synchronizace. K tomu poznámky a úkoly synchronizované přes IMAP.

Webmail a správa v češtině

Plnohodnotný webový klient: čtení, psaní, přílohy, podpisy, pravidla třídění, kalendář, „mimo kancelář". Správcovské rozhraní s přehledem provozu, frontou, karanténou a logem serveru.

Doručitelnost na úrovni velkých

SPF, DKIM (podpis i ověření), DMARC včetně souhrnných hlášení, MTA-STS, DANE a SRS pro přeposílání. Server vám rovnou vypíše DNS záznamy a zkontroluje, že sedí.

Certifikáty se řeší samy

Vestavěný Let's Encrypt klient certifikáty vydává i obnovuje automaticky. Sklad certifikátů s výběrem podle jména (SNI), import i export — bez certbota a bez restartů.

Ochrana bez příplatků

Filtr spamu s DNSBL/SURBL, greylisting, vlastní pravidla, limity na IP. Filtr příloh blokuje spustitelné soubory i uvnitř ZIPu. Karanténa, volitelně ClamAV — žádný placený antivirusový modul.

Firemní přihlašování

Napojení na Active Directory / OpenLDAP včetně zakládání schránek z adresáře, přihlášení přes OAuth poskytovatele a hesla aplikací pro mobilní klienty.

Kvóty, aliasy, domény

Víc domén na jednom serveru, aliasy a distribuční skupiny, sběrné schránky, kvóty na místo i počet položek s varováním e-mailem, zápatí domény, promazávání staré pošty. Delegování schránky kolegovi — číst, třídit i odesílat za šéfa.

Komunitní verze, licence a cloud

Server je pořád jeden a tentýž — licence jen odemyká počet schránek. Cloud je volitelný doplněk pro ty, kdo spravují víc serverů.

Komunitní verze — zdarma

  • až 5 schránek, všechny funkce serveru
  • bez registrace a bez licenčního klíče
  • nikam se nehlásí — běží i v uzavřené síti
  • ideální pro malou firmu, rodinu nebo vyzkoušení

Licence — schránky bez omezení

  • licence na server, ne na uživatele
  • ověřuje se u licenčního serveru dvakrát denně; výpadek spojení nevadí 14 dní
  • aktualizace se nabídnou ve správě a nainstalují po potvrzení (Windows, Linux), Docker si stáhne nový image
  • po vypršení se nic nemaže a pošta se doručuje dál — server se jen zúží na pět schránek, po prodloužení se vše vrátí

Crossui Cloud — volitelně

  • správa více serverů na jednom místě — třeba všech vašich zákazníků
  • server se připojí sám ven, u zákazníka se neotevírá žádný port
  • sdílení serverů s kolegy: vlastník, správce, jen čtení — v logu je vidět, kdo co udělal
  • pošta v cloudu neleží nikdy; bez cloudu server funguje stejně

Rozjetí za pět minut

Žádná databáze, žádné další služby. Jeden kontejner, jeden svazek — index i pošta leží v /var/lib/crossui-mail a záloha je kopie tohoto adresáře.

docker run -d --name crossui-mail \
  -e "MailServer__Hostname=mail.priklad.cz" \
  -p 25:2525 -p 587:5587 -p 465:4465 \
  -p 143:1143 -p 993:9993 \
  -v crossui-mail-data:/var/lib/crossui-mail \
  ghcr.io/cudaint/crossmailserver:latest

Server si při prvním startu sám vytvoří index, vystaví certifikát a vypíše správcovský klíč do logu. Běží jako non-root, obraz je pro amd64 i arm64. Domény, schránky, porty i bezpečnostní politiku pak nastavíte ve správě v prohlížeči. Bez licence běží jako komunitní verze do pěti schránek; licenční klíč se dá vložit kdykoli později.

Navrženo pro jeden server — schválně

Crossui Mail Server necílí na cloudové flotily s tisíci uzly. Je stavěný pro firmu do stovek schránek na jednom stroji: proto vystačí s jedním procesem, jedním adresářem dat a nulou externích závislostí — a proto se dá spravovat za zlomek času. Změny portů, certifikátů i pravidel platí za běhu, bez restartu. Kdo má takových serverů víc, spravuje je z jednoho místa přes Crossui Cloud.
